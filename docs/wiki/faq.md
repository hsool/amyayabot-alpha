# FAQ

## 꼭 모든 기능을 켜야 하나요?

아니요. 기본 방송 보조만 원하면 **Gemini API 키 + 오버레이 + CHZZK 연결**만으로 시작할 수 있습니다. STT, OBS, Vision, 신청곡, Naver 공식 검색/팬카페 조회는 필요한 방송 스타일에 맞춰 추가로 켜면 됩니다.

## 일반 시청자에게 가장 먼저 보이는 장점은 무엇인가요?

- 채팅과 후원에 캐릭터가 말풍선·음성·채팅으로 반응합니다.
- 말투, 관계성, 금칙어, 출력 길이를 방송 콘셉트에 맞출 수 있습니다.
- OBS 오버레이로 캐릭터·말풍선·신청곡·투표/룰렛 화면을 분리할 수 있습니다.
- 장기기억과 검색 보조 기능을 켜면 이전 방송 맥락이나 웹 검색 결과를 답변에 보조 정보로 사용할 수 있습니다.

## 다른 챗봇과 같이 써도 되나요?

가능합니다. 다만 명령어 접두사와 중복 명령을 먼저 확인하세요. AmyayaBot의 기본 명령어 접두사는 `!`이고, 투표·추첨·룰렛·신청곡 같은 기능이 같은 접두사를 사용할 수 있습니다. 중복이 있다면 AmyayaBot 쪽 명령어를 끄거나 다른 접두사로 바꾸는 편이 안전합니다.

## API 키를 꼭 넣어야 하는 기능은 무엇인가요?

| 기능 | 필요한 값 | 없으면 어떻게 되나요? |
| --- | --- | --- |
| AI 반응 | Gemini API key | 캐릭터 답변 생성 불가 |
| CHZZK 연결 | Client ID, Client Secret, OAuth 승인 | 채팅/후원 수신 및 채팅 응답 불가 |
| 팬카페 숫자 ID 조회 | `cafeId`/`clubid` | 팬카페 최신 공개글 기반 검색 불가. Naver API 키는 필요 없음 |
| Naver 공식 검색 | Client ID, Client Secret | 일반 웹/카페글 공식 검색과 팬카페 이름·URL slug 후처리 필터 사용 불가 |
| Supertone/Fish TTS | 각 서비스 API key | 해당 TTS 엔진 사용 불가 |

API 키가 없어도 오버레이 화면, 일부 설정 UI, 기본 캐릭터 배치는 확인할 수 있습니다.

## CHZZK Client ID와 Secret만 있으면 봇이 채널 권한을 얻나요?

아니요. Client ID/Secret은 애플리케이션 식별용 값이고, 실제 채널 권한은 스트리머가 OAuth 승인 과정을 거쳐야 얻습니다. 그래도 공개 저장소에는 Secret을 남기지 않는 것이 원칙입니다.

## OBS WebSocket은 왜 필요한가요?

OBS WebSocket은 AmyayaBot이 현재 장면을 읽고, Vision 캡처 대상을 찾고, 일부 장면 기반 정책을 적용하기 위해 사용합니다. 기본 오버레이만 쓰는 경우에도 OBS에는 Browser Source를 추가해야 하지만, Vision·장면 감지까지 쓰려면 OBS WebSocket 연결이 필요합니다.

## Vision은 꼭 필요한가요?

아니요. Vision은 게임 화면/OBS 장면을 보조 분석하는 실험적 기능입니다. 기본 채팅 반응에는 필요하지 않습니다. 다만 게임 HUD나 특정 화면 상태를 반응 조건으로 쓰고 싶다면 OBS 연결과 함께 켜는 것이 좋습니다.

## STT는 무엇을 하나요?

STT는 스트리머 마이크 음성을 텍스트로 바꾸어 캐릭터가 방송자의 발화를 참고하도록 돕습니다. 조용한 방송에서는 끄는 편이 가볍고, 토크 방송에서는 켜면 캐릭터가 방송자 발화에 맞춰 반응하기 쉬워집니다.

## 팬카페 cafeId / clubid 필드는 무엇인가요?

팬카페 cafeId / clubid 필드는 `source=naver_cafe` 검색 결과를 특정 팬카페로 좁히기 위한 연결 설정입니다. 숫자 `clubid`/`cafeId`를 입력하면 네이버 카페 웹의 boardlist API로 해당 팬카페 최신 공개글을 가져온 뒤 로컬 검색합니다. 이 숫자 ID 경로는 Naver Client ID/Secret이 없어도 동작합니다. “조회수 많은 글”, “댓글 많은 글”, “좋아요 많은 글” 요청은 최근 공개글 안에서 해당 지표로 정렬합니다. URL slug나 팬카페 이름을 입력하면 공식 Naver 카페글 검색 API 결과의 `cafename`/`cafeurl`을 후처리해 설정한 팬카페와 맞는 항목만 사용합니다. 비공개/멤버 전용 글은 가져올 수 없고, boardlist 경로는 비공식 API라 네이버 정책 변경에 영향을 받을 수 있습니다.

## 설정을 바꿨는데 방송 화면이 그대로예요.

대부분 다음 중 하나입니다.

1. 설정 페이지에서 저장하지 않았습니다.
2. OBS Browser Source가 오래된 캐시를 보고 있습니다.
3. 백엔드 서비스가 아직 이전 설정으로 실행 중입니다.
4. CHZZK/OBS/STT처럼 연결형 서비스는 저장 후 별도 재연결이 필요합니다.

빠른 확인 순서: 저장 → 브라우저/OBS 소스 새로고침 → 서비스 상태 확인 → 필요한 서비스 재연결.

## 기존 v1 문서는 어디에 있나요?

`docs-legacy/v1`에 참고용으로 보존했습니다. 현재 공개 문서의 기준은 `docs/`와 `README.md`이며, v1은 과거 화면·흐름을 확인할 때만 보조로 사용하세요. 오래된 v2 phase 문서는 현재 문서와 섞이지 않도록 제거했습니다.
